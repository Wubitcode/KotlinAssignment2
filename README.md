# Project Overview

This project contains solutions to four Kotlin programming challenges involving
string encryption, anagram comparison, substring detection, and word analysis.

The project was created using IntelliJ IDEA and is managed using Git and GitHub.

# Challenges

# Challenge A: String Encryption

Creates an encrypted version of a supplied string by shifting each alphabetic
character by a supplied integer key.

The function supports:

- Uppercase letters
- Lowercase letters
- Letter wrapping, such as `z` becoming `a`
- Positive and negative keys
- Spaces, numbers, and punctuation

# Challenge B: Anagram Checker

Compares two single words and determines whether they are anagrams of each other.

For example:


dusty and study → true
hello and world → false

# Challenge C: Substring Checker

Determines whether the second string is a substring of the first string.

The solution performs a manual character-by-character comparison and does not
use the Kotlin String.contains() method.

# Challenge D: Longest Word Finder

Analyzes a supplied string and returns the longest word found in that string.

Punctuation and spaces are handled when identifying individual words.
